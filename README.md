# Pixel：AI 像素风图片转换项目

一个使用 Python 开发的 AI 像素风图片转换项目。

本项目的目标是制作一个网页应用：用户上传现实照片后，系统调用外部 AI 服务，将照片转换成像素风图片，并向用户提供预览和下载功能。

> 🚧 项目正在开发中。目前已完成基础的图片检查功能，Web 接口、AI 图片转换和网页界面尚未实现。

## 项目目标

项目计划实现以下完整流程：

1. 用户在网页中上传一张现实照片。
2. 后端检查文件是否为空、格式是否正确、文件是否过大。
3. 后端把通过检查的图片发送给外部 AI 图片服务。
4. AI 服务生成对应的像素风图片。
5. 网页展示转换结果，并允许用户下载生成的图片。

## 本地安装

### 1. 克隆仓库

```bash
git clone https://github.com/ddddelicious/pixel.git
cd pixel
```

### 2. 安装依赖

请先在电脑上安装 Python 3.13 和 `uv`，然后执行：

```bash
uv sync
```

`uv` 会根据 `pyproject.toml` 和 `uv.lock` 安装项目需要的依赖。

## 当前图片检查规则

`src/pixel/services/images.py` 中的 `check_image()` 函数目前会进行以下检查：

1. 图片数据不能为空。
2. 图片文件不能超过 5 MB。
3. 图片的真实格式必须是 JPEG 或 PNG。
4. 图片的宽度和高度都不能超过 4096 像素。
5. 图片内容必须能够被 Pillow 正常读取。

检查成功后，函数会返回图片格式、宽度和高度，例如：

```python
("PNG", 1024, 768)
```

当前项目还没有可启动的 Web 服务或图形界面。
